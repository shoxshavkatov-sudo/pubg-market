# Подключение к Telegram (Mini App)

Приложение уже адаптировано под Telegram Mini App. Внутри Telegram оно само:
- открывается на весь экран (без рамки iPhone), блокирует случайное сворачивание свайпом вниз;
- берёт светлую или тёмную тему из Telegram и красит шапку и фон;
- подставляет имя, @username и фото из вашего аккаунта Telegram в профиль (при первом запуске);
- показывает системную кнопку «Назад» в чатах и шторках;
- вызывает вибрацию Telegram (haptic) вместо браузерной;
- делает «Поделиться» через окно отправки Telegram и принимает реферальный код из ссылки (`startapp=ref_КОД`).

Вне Telegram (в обычном браузере) оно работает как раньше.

## Что понадобится
- аккаунт Telegram;
- сайт на Render с HTTPS (Mini App работает только по https), см. README.md.

## Шаг 1. Создайте бота
1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Введите название и username (должен заканчиваться на `bot`, например `MarketPubgBot`).
3. BotFather пришлёт **токен**. Храните его в секрете и не кладите в репозиторий.

## Шаг 2. Создайте Mini App
1. В @BotFather отправьте `/newapp` и выберите своего бота.
2. Заполните название, описание, картинку 640×360 (можно пропустить командой `/empty`) и GIF (тоже `/empty`).
3. **Web App URL**: адрес сайта на Render, например `https://pubg-market.onrender.com`.
4. **Short name**: короткое имя, например `market`.

BotFather пришлёт ссылку вида `https://t.me/MarketPubgBot/market`. Она открывает приложение в Telegram.

## Шаг 3 (по желанию). Кнопка меню у бота
`/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** → отправьте адрес сайта и название кнопки, например «Открыть».
Теперь у бота рядом с полем ввода появится кнопка запуска приложения.

## Шаг 4. Пропишите ссылку в приложении
Откройте `public/index.html`, найдите в начале файла:
```js
window.MARKET_CONFIG={tgAppLink:""};
```
и вставьте свою ссылку из шага 2:
```js
window.MARKET_CONFIG={tgAppLink:"https://t.me/MarketPubgBot/market"};
```
Затем отправьте обновление: `./update.sh "Ссылка на Mini App"`.
После этого кнопки «Поделиться» и реферальные ссылки будут вести сразу в ваше приложение в Telegram.

## Шаг 5. Проверьте
1. Откройте ссылку `https://t.me/ВАШ_БОТ/market` и нажмите «Открыть».
2. Должно быть: приложение на весь экран, тема как в Telegram, в профиле ваше имя и @username, в чате в шапке Telegram появляется стрелка «Назад».

## Обновление приложения
1. Измените файлы, выполните `./update.sh "что изменили"`.
2. Render пересоберёт сайт за 1–2 минуты.
3. В Telegram закройте приложение и откройте заново, чтобы подтянулась новая версия.

## Отладка внутри Telegram
- **Android**: Telegram → Настройки → 10 раз нажать на номер версии → включить **Enable WebView Debug**, затем в Chrome на компьютере откройте `chrome://inspect`.
- **iOS**: Настройки → Advanced → Experimental → **Enable WebView Inspection**, затем Safari на Mac → Develop.
- **Telegram Desktop (Windows, Linux)**: Settings → Advanced → Experimental → **Enable webview inspecting**, затем правый клик в приложении → Inspect.

## Важно знать
- **Данные хранятся на устройстве.** Объявления, чаты, профиль и карта лежат в памяти браузера внутри Telegram. На другом устройстве или после очистки данных их не будет. Общие данные между людьми потребуют сервера.
- **Данным пользователя из Telegram нельзя доверять без проверки.** Сейчас имя и фото берутся только для удобства. Когда появится сервер, проверяйте подпись `initData` (HMAC-SHA256 с ключом из токена бота), прежде чем что-то разрешать.
- **Оплата.** Для платежей понадобится бот-сервер и Telegram Payments или Stars. В шаблоне оплата только имитируется.
- **Токен бота** нигде не используется в этом сайте. Не добавляйте его в публичный репозиторий.

## Если что-то не работает
- Белый экран или «не удалось открыть»: проверьте, что адрес в BotFather начинается с `https://` и сайт на Render открывается в обычном браузере.
- Старая версия: закройте и откройте приложение заново, при необходимости очистите кэш Telegram.
- Нет кнопки «Назад»: обновите Telegram, функция есть в версиях с Bot API 6.1 и новее.
