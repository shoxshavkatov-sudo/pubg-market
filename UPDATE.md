# Как обновить сайт в Git (самый простой способ)

Обновление всегда проходит одинаково: **скачали архив → одна команда → через 1–2 минуты сайт обновился**.

> **Один раз при переходе на эту версию:** в Render нужно удалить старый Static Site и создать сервис заново через Blueprint (см. `DEPLOY.md`, шаг 2). После этого обновления идут как обычно.

## Каждый раз
1. Скачайте последний архив `pubg-market-deploy.zip` из ответа (он сохранится в папку «Загрузки»).
2. Откройте Терминал и выполните две команды (подставьте путь к своей папке проекта):
```bash
cd ~/Documents/pubg-market-deploy
bash apply-update.sh "что изменили"
```
Скрипт сам:
- найдёт самый свежий архив в «Загрузках»;
- скопирует новые файлы в проект (ваш `public/config.js` с адресом сервера и ссылкой Telegram **не трогает**);
- сделает коммит и отправит его в GitHub.

3. Подождите 1–2 минуты: Render пересоберёт сайт. В Telegram закройте Mini App и откройте заново.

Если скрипт написал «Изменений нет», значит, в архиве та же версия, что уже в проекте.

## Один раз: если в вашей папке ещё нет `apply-update.sh`
Распакуйте новый архив и скопируйте файлы вручную (точка в конце команды обязательна):
```bash
cd ~/Downloads
unzip -o pubg-market-deploy.zip -d new-version
cp -R new-version/pubg-market-deploy/. ~/Documents/pubg-market-deploy/
cd ~/Documents/pubg-market-deploy
bash update.sh "Обновление"
```
Дальше всегда пользуйтесь `apply-update.sh`.

## Без скрипта (вручную)
```bash
cd ~/Documents/pubg-market-deploy
git add .
git commit -m "что изменили"
git push
```

## Как проверить, что всё ушло в GitHub
```bash
git status          # должно быть: nothing to commit, working tree clean
git log --oneline -3   # сверху ваш свежий коммит
```
Затем откройте репозиторий на github.com: время последнего коммита должно быть свежим.

## Что делать, если ошибка
| Что вы видите | Что делать |
|---|---|
| `Не нашёл архив pubg-market-deploy*.zip` | Скачайте архив ещё раз, он должен лежать в «Загрузках». |
| `Изменений нет` | В архиве та же версия. Скачайте новый архив из последнего ответа. |
| `nothing to commit` при ручном способе | Файлы не скопированы в папку проекта. Используйте `apply-update.sh`. |
| `not a git repository` | Вы не в папке проекта. Выполните `cd ~/Documents/pubg-market-deploy`. |
| `rejected ... non-fast-forward` | Выполните `git pull --rebase`, затем снова `bash apply-update.sh "..."`. |
| `Authentication failed` | Для GitHub нужен токен вместо пароля (инструкция в `DEPLOY.md`, шаг 2). |
| `Permission denied` | Запускайте командой `bash apply-update.sh`, а не `./apply-update.sh`. |
| Сайт не обновился | Подождите 2 минуты, проверьте вкладку **Events** в Render, обновите страницу. |
| В Telegram старая версия | Закройте Mini App и откройте заново. |

## Что обновляется, а что нет
- Обновляются: `public/index.html`, `server/`, `render.yaml`, скрипты и инструкции.
- **Не** перезаписывается: `public/config.js`. В нём ваши настройки: адрес сервера чата (`api`) и ссылка Mini App (`tgAppLink`).
