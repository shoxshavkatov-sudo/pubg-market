# Market: маркетплейс аккаунтов PUBG Mobile

Лента объявлений, чат в стиле Telegram, профиль с верификацией, кошелёк с 3D-картой и безопасная сделка через гарант (6 шагов).
Работает как обычный сайт и как **Telegram Mini App**. Люди видят объявления друг друга и общаются по-настоящему: для этого есть небольшой сервер (Node, без зависимостей), который раздаёт и сайт.

## Структура
```
public/index.html          приложение
public/config.js           ваши настройки (ссылка Telegram; адрес сервера обычно пустой)
public/landing/            страница «Coming soon»
public/logo.svg, brand/    логотип и фирменные картинки
server/                    сервер: сайт + чат + общие объявления + сделки
render.yaml                настройки Render (один сервис)
push-to-github.sh          первая отправка в GitHub
apply-update.sh            обновление одной командой из скачанного архива
update.sh                  отправка обновлений вручную
DEPLOY.md  UPDATE.md  TELEGRAM.md  SERVER.md  TEST.md   инструкции
```

## Быстрый старт
- **Запуск у себя:** `node server/index.js`, затем http://localhost:8787 (нужен Node.js 18+).
- **Деплой:** `DEPLOY.md`. **Обновления:** `UPDATE.md`. **Telegram:** `TELEGRAM.md`. **Проверка общения:** `TEST.md`.

## Сделка через гарант (6 шагов)
1. Договор о стоимости: одна сторона предлагает цену, другая соглашается.
2. Оплата: система распознаёт баланс покупателя, при нехватке предлагает пополнить, замораживает деньги на гарант-счёте.
3. Удаление лишних (верхних) привязок: продавец отвязывает, покупатель проверяет.
4. Смена основных привязок: покупатель меняет почту и номер, коды называет продавец.
5. Подтверждение покупателем: чек-лист проверки аккаунта.
6. Выплата продавцу: деньги за вычетом комиссии зачисляются продавцу.
Есть спор (деньги замораживаются) и отмена до оплаты. Состояние сделки общее для обеих сторон.

## Что важно знать
- Платежи и баланс тестовые: реальные деньги не списываются. Для настоящих платежей нужен платёжный провайдер.
- Данные на сервере хранятся во временном файле (на бесплатном Render пропадают при перезапуске). Подробности в `SERVER.md`.
- Пользовательские данные (объявления, переписка, профиль) хранятся и в браузере пользователя.
